# Cypress

Exercícios e entregas do curso **Cypress, do Zero à Nuvem**, de Walmyr Filho, e da documentação complementar. Esta pasta faz parte da semana 2 da trilha QA Path.

- [Curso na Udemy](https://www.udemy.com/course/testes-automatizados-com-cypress-basico/)
- [Documentação Cypress](https://docs.cypress.io/app/get-started/why-cypress)

Entrega esperada: suíte E2E com cenários positivos e negativos, fixtures, interceptação de requisições e instruções de execução.

Cada projeto deve incluir código, testes e um README com objetivo, requisitos, como executar e resultados observados. Quando o envio pelo QA Path estiver ativado, as entregas serão publicadas em subpastas identificadas, preservando este guia e os projetos anteriores.

As entregas práticas ainda serão adicionadas durante os estudos.
