# GitHub Actions

Exercícios e entregas da semana 11: execução automatizada de testes, artefatos, relatórios e integração com Pull Requests.

[Material de estudo](https://docs.github.com/en/actions/get-started/quickstart)

Esta pasta guarda exemplos e documentação. Workflows ativos precisam estar em `.github/workflows/` na raiz do repositório correspondente; um YAML enviado para uma subpasta de curso é apenas um exemplo e não ativa a execução automaticamente.

Cada entrega deve descrever os eventos do workflow, comandos, dependências e resultados. O QA Path publicará cada envio em uma nova subpasta quando a integração estiver ativada.

As entregas práticas ainda serão adicionadas durante os estudos.
