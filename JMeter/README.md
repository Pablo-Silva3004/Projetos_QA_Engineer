# Apache JMeter

Exercícios e entregas da semana 9: testes de carga e estresse em ambientes próprios de teste, análise de latência e taxa de erros.

[Material de estudo](https://jmeter.apache.org/usermanual/get-started.html)

Cada entrega deve incluir plano JMeter, configuração da carga, instruções de execução e relatório com resultados, limitações e conclusões. O QA Path publicará cada envio em uma nova subpasta quando a integração estiver ativada.

As entregas práticas ainda serão adicionadas durante os estudos.
