# Playwright

Exercícios e entregas da semana 3: reproduzir parte da suíte Cypress em Playwright, explorar locators, assertions, fixtures, execução paralela, screenshots e traces.

[Material de estudo](https://playwright.dev/docs/intro)

Cada entrega deve ter código de testes, instruções de execução e evidências dos resultados. O QA Path publicará cada envio em uma nova subpasta quando a integração estiver ativada.

As entregas práticas ainda serão adicionadas durante os estudos.
