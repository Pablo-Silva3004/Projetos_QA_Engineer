# Postman e testes de API

Exercícios e entregas das semanas 5 e 6: HTTP, coleções Postman, autenticação, validações de resposta, contratos e cenários negativos.

[Material de estudo](https://learning.postman.com/docs/getting-started/overview/)

Cada entrega deve incluir a coleção ou código dos testes, ambiente de exemplo sem credenciais reais, instruções de execução e resultados. O QA Path publicará cada envio em uma nova subpasta quando a integração estiver ativada.

As entregas práticas ainda serão adicionadas durante os estudos.
